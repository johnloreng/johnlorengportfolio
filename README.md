# John Loreng — Detailed React Portfolio

A responsive software-engineering portfolio built with **React + Vite**.

## Includes

- Professional hero section
- About and engineering principles
- Current and previous professional experience
- Detailed LiquorFlow and Meridian Pivot case studies
- Challenge / Action / Result project storytelling
- Technical skills
- Certifications and education
- Engineering focus
- Contact section
- Responsive mobile navigation
- Dark/light theme toggle
- GitHub and LinkedIn links

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The `dist/` folder is ready for static deployment to Vercel.
